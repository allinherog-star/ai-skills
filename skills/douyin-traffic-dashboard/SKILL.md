# 抖音流量分配大盘（拍什么有流量）

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

本技能展示抖音 32 个一级内容分类的热点数量和占比。统计基于一次采集的最多 100 条上升热点样本，按分类计数后计算占比；它不是全站播放量、曝光量，也不能代表某个账号或某条视频的实际流量表现。当前样本中没有上升热点的分类会显示为 0，不等于该赛道没有流量。

### 什么时候使用

**适用场景**

- 查看抖音上升热点样本当前分布在哪些一级内容分类
- 粗略比较美食、体育、娱乐等分类在这批样本中的热点数量和占比
- 做平台级方向观察、内容矩阵规划或运营复盘

**不适用场景**

- 评估某个账号的播放、涨粉、互动或转化表现
- 查询某个细分赛道或具体选题的热点列表
- 把分类占比当作抖音全站真实播放量或流量份额

要继续找具体热点，可使用「抖音实时上升热点」技能 `douyin-realtime-hot-rise` 按关键词和热点条目分析。

### 调用方式

通过导出的 Python runner 调用 AI Skills API。本技能不需要业务参数：

```bash
python3 scripts/run.py --params '{}'
```

### 返回结果示例

以下数据仅用于说明字段结构，数量与比例会随采集结果变化。

```json
{
  "success": true,
  "data": {
    "categories": [
      {
        "label": "美食",
        "value": "9000",
        "hotCount": 28,
        "percentage": 28,
        "icon": "UtensilsCrossed",
        "description": "探店、烹饪、美食测评",
        "group": "life"
      },
      {
        "label": "体育",
        "value": "5000",
        "hotCount": 11,
        "percentage": 11,
        "icon": "Dumbbell",
        "description": "赛事、运动、健身",
        "group": "life"
      }
    ],
    "total": 32,
    "updateTime": "2026-11-06T03:30:00.000Z"
  },
  "meta": {
    "executionTime": 842,
    "cached": false
  }
}
```

字段说明：

- `categories`：固定覆盖 32 个一级分类；`hotCount` 是采集样本中归入该分类的上升热点条数，`percentage` 是该分类热点数占已归类样本总数的百分比，按整数四舍五入。
- `value`：该分类关联的标签 ID 字符串，不是热度值。
- `total`：分类数量，不是热点条数。
- `updateTime`：结果生成时间，不是上游数据更新时间。若 `meta.cached` 为 `true`，返回的是缓存结果，时间会更早；采集失败时也可能沿用已有数据，因此不能单独用它判断样本新鲜度。

### 数据更新与限制

- 上游数据来自抖音上升热点榜；每次同步最多读取 100 条上升热点，并按返回的分类标签统计。
- 技能执行结果最长缓存 24 小时；`meta.cached: true` 表示本次命中执行缓存。实际采集也受服务端缓存影响：实例成功刷新后，5 分钟内会跳过重复采集；数据库中的分类数据超过 24 小时才触发持久化刷新检查。刷新失败时可能继续返回已保存的数据。
- 结果是某次有限样本的分类分布快照，不能据此推断全站真实流量份额或账号表现。分类为 0 只表示本次样本未采到该类上升热点。
- 本技能只展示一级分类汇总，不提供分类内的具体热点、细分赛道排名或账号级指标。

### 使用建议

- 先比较 `hotCount` 和 `percentage`，再结合自身账号定位、内容能力和受众判断方向，不要只追占比最高的分类。
- 查看连续多次结果时，记录各次样本时间；`updateTime` 是响应生成时间，采集失败时可能使用旧数据。
- 想看具体选题时，转到 `douyin-realtime-hot-rise` 查询热点条目，再按自己的受众与内容形式筛选。

### 常见问题

- **为什么某个分类是 0？** 当前采集样本可能没有归入该类的上升热点；这不代表该分类没有播放量或用户。
- **占比是全站流量占比吗？** 不是。它是最多 100 条上升热点样本中，各分类热点条数的比例，不是播放量、曝光量或全站流量份额。各分类按整数分别四舍五入，占比相加可能不正好等于 100%。
- **数据多久更新？** 技能结果缓存最长 24 小时；`meta.cached` 为 `true` 时表示直接复用了缓存。未命中缓存时，服务成功刷新后通常 5 分钟内不会重复采集；数据库数据超过 24 小时会触发刷新检查。上游失败时可能返回已有数据，`updateTime` 仅表示结果生成时间。
- **能查具体选题或个人账号吗？** 不能。本技能只返回一级分类汇总；具体热点请用 `douyin-realtime-hot-rise`，账号指标请使用账号分析类技能。
- **提示密钥缺失怎么办？** 登录 [ai-skills.ai](https://ai-skills.ai) 获取并设置 `AISKILLS_API_KEY`，然后重试。缺密钥与余额不足是不同问题。
- **提示余额不足怎么办？** 前往[账户充值页](https://ai-skills.ai/user/billing)充值后重试。
- **网络请求或证书验证失败怎么办？** 检查网络连接和系统证书；如本机使用自定义 CA，可设置 `SSL_CERT_FILE` 指向 CA bundle 后重试。请求超时后 runner 会结束并提示重试。
