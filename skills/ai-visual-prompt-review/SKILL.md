# ai-visual-prompt-review 视觉质量诊断助手

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

视觉质量诊断助手用于回答「这张图够发布吗」、AI绘图、提示词、豆包，适合设计、运营、市场营销、内容创作者在明确业务目标、内容材料或分析对象后调用。
它会结合视觉生成提示词、粘贴中文/英文提示词、负面提示、构图、主体、风格和用途说明。等输入，整理关键上下文，并输出摘要、诊断结论、行动建议和可复用交付物，便于继续执行、复盘或交付。

### 什么时候使用

**适用场景**

- 用户提出“这张图够发布吗”这类问题，需要快速拆解目标、判断重点并形成可执行结果
- 设计、运营、市场营销、内容创作者需要围绕视觉质量诊断助手生成摘要、诊断结论、行动建议和可复用交付物
- 用户已经准备了风格限制与风险点（补充禁用元素、版权顾虑、人物/品牌限制、色彩和构图偏好。）、上传视觉参考（上传参考图、品牌视觉规范、产品图、分镜或生成结果。）、视觉生成提示词（粘贴中文/英文提示词、负面提示、构图、主体、风格和用途说明。），希望整理成可执行的分析或优化结果
- 用户需要把视觉质量诊断助手相关材料转成清晰结论、优先级和下一步动作

### 调用方式

通过导出的 Python runner 直接调用 AI Skills API：

### 命令示例

**基础调用**

```bash
python3 scripts/run.py --params '{}'
```

**带常用参数调用**

```bash
python3 scripts/run.py --params '{"brandStyleNotes":"风格限制与风险点"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `brandStyleNotes` | string | 否 | - | 补充禁用元素、版权顾虑、人物/品牌限制、色彩和构图偏好 |
| `promptAssetFile` | string | 否 | - | 上传参考图、品牌视觉规范、产品图、分镜或生成结果 |
| `visualPromptText` | string | 否 | - | 粘贴中文/英文提示词、负面提示、构图、主体、风格和用途说明 |
| `visualGoalContext` | string | 否 | - | 说明用途、画幅、平台、目标受众、品牌要求和交付规格 |
| `visualReviewFocus` | string | 否 | `清晰度` | 选择本次AI视觉Prompt审查最需要优先处理的方向；可选值：`清晰度`、`风格一致`、`可控性`、`风险提示` |
| `imageReferenceLink` | string | 否 | - | 填写公开可访问的参考图、商品页、风格案例或素材链接；需要传可访问的完整 URL |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 摘要、诊断结论、行动建议和可复用交付物：围绕用户目标整理可直接阅读、复盘或交付的核心结果。
- 输入材料解读：结合风格限制与风险点（补充禁用元素、版权顾虑、人物/品牌限制、色彩和构图偏好。）、上传视觉参考（上传参考图、品牌视觉规范、产品图、分镜或生成结果。）、视觉生成提示词（粘贴中文/英文提示词、负面提示、构图、主体、风格和用途说明。）提炼关键上下文和判断依据。
- 下一步动作：给出优先级、执行建议或可继续加工的内容框架。

### 结果使用建议

- 先判断输出是否回答了用户关于「视觉质量诊断助手」的核心问题。
- 再检查结果是否覆盖摘要、诊断结论、行动建议和可复用交付物，以及是否给出明确下一步动作。
- 如果输入材料较少，建议让用户补充目标、受众、限制条件或原始材料后再运行。
