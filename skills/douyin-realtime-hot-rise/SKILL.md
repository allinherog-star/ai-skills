# 抖音实时上升热点（抖音热点趋势选题助手）

[快速开始](https://github.com/allinherog-star/ai-skills/tree/main#%E5%BF%AB%E9%80%9F%E5%BC%80%E5%A7%8B)

[更多技能](https://ai-skills.ai)

### 概述

查询抖音实时上升热点、飙升话题和热度趋势，`正在上升的热点，你才有空间，助力内容选题`。当用户想知道哪些话题正在升温、抖音上升榜有哪些热点、某关键词的排名或热度如何变化，或要按关键词/分类筛选热点时使用。典型请求包括“最近抖音什么话题在涨”“查这个关键词的抖音上升趋势”“接下来拍什么选题”。返回热点关键词、分类、当前排名、排名变化、热度值、趋势点和更新时间，支持热点跟进与选题判断。

### 什么时候使用

**适用场景**

- 用户问「最近抖音什么话题正在升温」「抖音上升榜/飙升榜有哪些热点」
- 用户要查看某个关键词的抖音热度、排名变化或趋势
- 用户按热点分类或关键词筛选上升话题，为选题、运营跟进收集数据

### 使用示例

**按关键词追热点**

```bash
python3 scripts/run.py --params '{"keyword":"奥运","order":"rank_diff"}'
```

**按分类看热点**

```bash
python3 scripts/run.py --params '{"tag":"5000","order":"rank"}'
```

### 参数说明

| 参数 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `tag` | string | 否 | - | 分类 ID；必须使用分类接口返回的数字 ID，多个 ID 用英文逗号分隔，如 `5000,6000` |
| `order` | string | 否 | `rank_diff` | `rank` 按热度排序；`rank_diff` 按排名变化排序。未传时服务端默认按排名变化排序 |
| `keyword` | string | 否 | - | 搜索热点关键词，最多 100 个字符 |

完整机器可读参数结构见 `references/form-schema.json`。

### 交付内容

- 上升热点清单：给出关键词、分类、排名变化和热度趋势。
- 趋势判断依据：帮助判断热点是刚开始升温、持续走高还是已经接近峰值。
- 选题参考：可直接用于短视频脚本、内容会选题和赛道观察。

### 结果使用建议

- 优先关注排名变化明显、仍在上升、且与账号赛道匹配的关键词。
- 结合分类和趋势变化判断跟进窗口，尽量把热点转成具体脚本角度。
- 适合内容会、选题池更新和临时热点响应。


### 选题分析建议

需要深入选题判断时，请基于返回条目按以下步骤给出结论，并明确把数据事实和创作建议分开：

1. 先标明榜单更新时间、是否命中缓存、筛选条件和返回条数。
2. 按 `rankDiff`、`hotScore` 和 `trends` 找出正在上升且热度仍有支撑的词；`rankDiff` 为正表示排名上升，负数表示下降。
3. 结合用户提供的账号赛道、受众和制作能力，说明每个候选话题的匹配理由、可拍角度和主要风险；缺少这些信息时，明确结论只是通用参考。
4. 只用返回的趋势点描述趋势，不外推没有提供的历史数据；不要声称榜单覆盖全部话题。

分页或历史回看需求超出本技能当前能力时，说明限制，并建议缩小关键词或分类范围后重新查询。
